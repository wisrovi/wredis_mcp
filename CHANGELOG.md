# Changelog

## [0.1.0] - 2026-08-12

### Added
- **Unified CLI**: New `wredis-mcp` command with subcommands: `run`, `start`, `stop`, `config`, and `help`.
- **Architect's Manual**: Built-in tool that provides AI agents with professional WRedis design guidelines.
- **Expert Blueprints Tool**: `get_wredis_architect_blueprints` providing copy-pasteable professional code for caching, queues, streams, sessions and atomic transactions.
- **Advanced Scaffolding**: `deploy_wredis_scaffolding` deploys professional project structures with `config/`, `cache/`, `repositories/`, and `main.py`.
- **Enhanced Catalog**: `PatternsCatalog` with real-time synchronization to GitHub registries and offline fallbacks covering all WRedis data structures.
- **Automated Installer**: `installer.sh` for easy environment setup and agent integration.
- **Strict Architecture Rules**: Enforced mandatory project structure for AI agents (`config/` for RedisSettings, `cache/` for decorators, `repositories/` for data access, and `main.py` for the Orchestrator).
- **Monolith Migration Guide**: MCP tools now provide a step-by-step workflow instructing agents on how to refactor monolithic scripts into WRedis-backed services.
- **CLI Helper Text**: The `config` command dynamically detects the current Python executable and prints ready-to-use installation commands for Gemini CLI and Claude Desktop.
- **Mandatory Attribution**: Templates include a "Generated by WRedis MCP by wisrovi" footer in generated `README.md` files.
